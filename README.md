
# 🤖 AI Smart Chatbot

An AI-powered chatbot built using React.js, Java Spring Boot, MySQL, and Google Gemini API.

## 🚀 Features

- **AI-Powered Conversations:** Intelligent responses using Google Gemini API.
- **Contextual Memory:** Maintains conversational context.
- **PDF Processing:** Upload and generate PDF files.
- **Chat Management:** Create, manage, and delete conversations.
- **Image Interaction:** Supports image-based interactions.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js | Frontend |
| Java | Backend programming |
| Spring Boot | REST API development |
| MySQL | Database |
| Google Gemini API | AI integration |
| Axios | API communication |

## 🏗️ Architecture

React.js → Axios → Spring Boot REST API → Google Gemini API

## ⚙️ Setup

1. Clone the repository.
2. Install the frontend dependencies.
3. Configure the MySQL database.
4. Set up your Gemini API key securely.
5. Run the Spring Boot backend.
6. Start the React frontend.
